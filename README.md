# 🚙 Libo Racing

A fast, fun **hill climb racing game** that runs right in your browser, built with plain HTML5 Canvas and JavaScript. No frameworks, no dependencies, no build step: it is a single file that works great on mobile, especially on iPhone.

Drive your little red car across endless, procedurally generated hills, collect coins, grab fuel cans, and see how far you can go before you flip over or run dry.

## ✨ Features

- **Endless procedural terrain** that gets steeper and more challenging the further you drive
- **Physics-based driving** with spring suspension, wheel traction, wheelies and mid-air rotation
- **Coins and fuel cans** to collect along the way
- **Touch controls** designed for phones, plus keyboard support on desktop
- **Best distance saved** locally in your browser
- **Responsive layout** for both portrait and landscape screens
- **Zero dependencies**: just one HTML file

## 🎮 How to play

| Action | Touch | Keyboard |
| --- | --- | --- |
| Accelerate / lean back in the air | **GAS** (right button) | `→` or `D` |
| Brake / lean forward in the air | **BRAKE** (left button) | `←` or `A` |

- Keep an eye on the fuel bar: collect the red cans to refill.
- Grab coins to boost your score.
- The run ends if you flip over and hit the ground with your head, or if you run out of fuel and stop.

For the best experience on iPhone, rotate the device to **landscape**.

## 🚀 Run it

**Locally**

1. Download or clone this repository.
2. Open `index.html` in any modern browser.

**On your phone**

1. Host the file (for example with GitHub Pages, see below) and open the link in Safari.
2. Tap **Share → Add to Home Screen** to launch it full screen like a native app.

**With GitHub Pages**

1. Rename the game file to `index.html` and push it to your repository.
2. Go to **Settings → Pages**, choose your main branch and save.
3. Your game will be live at `https://<your-username>.github.io/<repository-name>/`.

## 🛠️ Tech notes

- Rendering with the HTML5 Canvas 2D API, scaled automatically to the screen size
- Custom physics engine: the car is a rigid body with two spring-damper wheels, solved with 4 substeps per frame for stability
- Terrain generated by combining sine waves, with amplitude increasing over distance
- Touch input handled through Pointer Events, so gas and brake can be pressed at the same time
- High score stored in `localStorage`
